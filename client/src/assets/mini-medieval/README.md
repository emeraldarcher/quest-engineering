# Mini Medieval assets

These documented source sheets are retained for historical and reference use.
The current production town does not import Mini Medieval artwork; it uses the
Sunnyside runtime subset under `client/src/assets/sunnyside/`.

`client/src/world/mini-medieval-assets.ts` preserves the old semantic frame
catalog for the v0.14a visual history and its frame-contract test. Historical
comparison screenshots also still depict Mini Medieval. Keeping the source,
license, and attribution records together ensures those retained references
remain correctly documented without exposing obsolete credits in gameplay UI.

See [ATTRIBUTION.md](ATTRIBUTION.md), [SOURCE.md](SOURCE.md), and the retained
[CC BY 4.0 text](license/CC-BY-4.0.txt).
