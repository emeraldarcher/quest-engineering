## Runtime and authoring subset

Only the following minimum runtime subset was copied from the 2.1 archive:

- `terrain/world-16px.png`: original 16px world tilesheet;
- `terrain/forest-32px.png`: original forest tilesheet;
- `foliage/`: selected original rounded-tree and pine-tree frames;
- `buildings/`: four small derived facades assembled from authored `Room1`
  building-layer tile recipes and the original 16px tilesheet;
- `characters/`: selected original Asset Pack 2.1 base and six hair-layer PNG
  strips for idle, walk, and doing;
- `animals/`: original bird, chicken, and duck strips;
- `effects/`: original smoke, fire, and glint strips;
- `props/`: selected original GameMaker composite sprite PNGs for district
  dressing; and
- `ui/`: selected original emote/plan icons.

Exact source paths, frame rectangles, timing, anchors, and purposes are recorded
in `client/src/world/runtime/sunnyside-assets.ts`. The Tiled project references
the same PNGs through external `.tsj` definitions; no second authoring copy or
embedded image data is maintained.

### Room1 design-reference subset

`reference/sunnyside-example/` contains only the composite sprite frames placed
by the artist in GameMaker `Room1`, including the representative animation frame
saved by each room asset graphic. They are generated by
`client/scripts/sunnyside-example-importer.ts` for the non-runtime
`sunnyside-example-world.tmj` reference map. This is not a copy of the
GameMaker project or the full asset pack.

The full ZIP, duplicate downloads, GameMaker project, example scene, GIF
variants, Aseprite sources, combat characters, and unused artwork are not stored
in the repository.

## Modifications and derived presentation

- Original copied PNG bytes are unchanged, but files were renamed semantically.
- `buildings/guild.png`, `forge.png`, `tavern.png`, and `projects.png` are
  transparent-cropped derived compositions of authored tiles from the example
  room. They contain no resampling or palette changes.
- Other terrain is framed at runtime from the original tilesheets.
- Character base and hair layers are composed at runtime.
- Warm Management and Soft Earthy are non-destructive runtime color treatments
  applied to terrain/environment layers; source PNGs are unchanged.
- Status glyphs, paths, district placement, fences, and labels are original
  Quest Engineering presentation code and do not alter the source files.
- No generated atlas or Aseprite conversion tooling is used by the authored-map pipeline.
- The original world and forest sheets are exposed to Tiled as external atlas
  tilesets; selected building/prop PNGs are exposed as an external image
  collection tileset.
