# v0.14a density checkpoint

The same deterministic 12-Member scene was inspected at 2×, 3×, and 4× at
1440×900, plus 1280×800 and 900×600.

Decision:

- **3× desktop default:** 24×24 displayed Members remain individually readable,
  status glyphs are clear, and a compact management window still leaves enough
  town for simultaneous work.
- **2× overview/minimum viewport:** the complete functional core and the largest
  population fit comfortably; identity detail is weaker but orders and state
  silhouettes remain usable because hit targets stay approximately 36 CSS px.
- **4× close:** excellent unit/glyph inspection but insufficient context for
  ordinary management, so it remains an explicit close view rather than default.

The screenshots also confirmed that 900×600 needs 2× initially and a constrained
side window. No asset-direction readability FLAG was required.
